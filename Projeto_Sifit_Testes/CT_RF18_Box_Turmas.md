# CENÁRIO 18: BOX – TURMAS

## CASO DE TESTE 01: ACESSAR E CONSULTAR MENU BOX – TURMAS

| ID        | DESCRIÇÃO                                                                                                                        |
| --------- | -------------------------------------------------------------------------------------------------------------------------------- |
| CT01-CT01 | Verificar se o menu Box – Turmas permite acessar e consultar as turmas disponíveis no SIFIT Box. |

| PRÉ-CONDIÇÕES |
|---|
| O usuário deve estar autenticado no sistema SIFIT e possuir permissão para acessar o menu Box – Turmas. |

| PASSOS |
|---|
| ACESSAR o site SIFIT. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Box – Turmas. |
| VERIFICAR se a página Box – Turmas é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR se existem opções de consulta ou visualização das turmas do SIFIT Box. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O sistema deve permitir o acesso ao menu Box – Turmas e apresentar corretamente as informações disponíveis, possibilitando a consulta conforme as funcionalidades implementadas. |
