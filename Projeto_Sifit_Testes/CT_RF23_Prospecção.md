| ID        | DESCRIÇÃO                                                                                                                   |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| CT01-CT01 | Verificar se o menu Prospecção permite acessar e consultar as informações dos clientes em potencial disponíveis no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
|---|

|---|

| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Prospecção. |
| VERIFICAR se a página de Prospecção é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR se existem opções de consulta ou visualização das informações de prospecção. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O sistema deve permitir o acesso ao menu Prospecção e apresentar corretamente as informações disponíveis, possibilitando a consulta conforme as funcionalidades implementadas. |
