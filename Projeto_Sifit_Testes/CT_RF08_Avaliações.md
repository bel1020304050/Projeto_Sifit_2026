CENÁRIO 08: AVALIAÇÕES

CASO DE TESTE 01: ACESSAR E CONSULTAR MENU AVALIAÇÕES

| ID | DESCRIÇÃO |
|--- |
| CT01-CT01 | Verificar se o menu Avaliações permite acessar e consultar as avaliações disponíveis no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
| --- |
| O usuário deve estar autenticado no sistema SIFIT e possuir permissão para acessar o menu Avaliações. |


| PASSOS |
| --- |
| ACESSAR o site SIFIT. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Avaliações. |
| VERIFICAR  se a página de Avaliações é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR e existem opções de consulta, pesquisa ou visualização das avaliações. |


| CRITÉRIOS DE PROTEÇÃO |
| --- |
| O sistema deve permitir o acesso ao menu Avaliações e apresentar corretamente as informações disponíveis, possibilitando a consulta das avaliações conforme as funcionalidades implementadas. |
