# CENÁRIO 19: CAIXAS

## CASO DE TESTE 01: ACESSAR E CONSULTAR MENU CAIXAS

| ID        | DESCRIÇÃO                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------- |
| CT01-CT01 | Verificar se o menu Caixas permite acessar e consultar as informações dos caixas disponíveis no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
|---|
| O usuário deve estar autenticado no sistema SIFIT e possuir permissão para acessar o menu Caixas. |

| PASSOS |
|---|
| ACESSAR o site SIFIT. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Caixas. |
| VERIFICAR se a página de Caixas é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR se existem opções de consulta ou visualização dos caixas. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O sistema deve permitir o acesso ao menu Caixas e apresentar corretamente as informações disponíveis, possibilitando a consulta conforme as funcionalidades implementadas. |
