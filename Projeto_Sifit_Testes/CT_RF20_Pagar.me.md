# CENÁRIO 20: PAGAR.ME

## CASO DE TESTE 01: ACESSAR E CONSULTAR MENU PAGAR.ME

| ID        | DESCRIÇÃO                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| CT01-CT01 | Verificar se o menu Pagar.me permite acessar e consultar as informações disponíveis sobre a integração de pagamentos no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
|---|
| O usuário deve estar autenticado no sistema SIFIT e possuir permissão para acessar o menu Pagar.me. |

| PASSOS |
|---|
| ACESSAR o site SIFIT. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Pagar.me. |
| VERIFICAR se a página Pagar.me é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR se existem opções de consulta ou visualização das informações disponíveis. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O sistema deve permitir o acesso ao menu Pagar.me somente a usuários autenticados e autorizados, apresentando corretamente as informações disponíveis. |
