CENÁRIO 06: CONSULTAR CLIENTES

CASO DE TESTE 01: VISUALIZAR E CONSULTAR O MENU CLIENTES

| ID | DESCRIÇÃO |
| --- |
| C01-CT01 | Verificar se o menu Clientes permite visualizar e consultar os clientes cadastrados no sistema SIFIT. |

| PRÉ-REQUISITOS |
| --- |
| O usuário deve estar autenticado no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
| --- |
| O usuário deve possuir permissão para acessar o menu Clientes. |

| PASSOS |
| --- |
| ACESSAR o sistema Sifit. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu "Clientes" |
| VERIFICAR se a página de clientes é exibida corretamente. |
| OBSERVAR os dados dos clientes apresentados na tela. |
| VERIFICAR se as opções disponíveis no menu estão funcionando corretamente. |

| CRITÉRIOS DE PROTEÇÃO |
| --- |
| O sistema deve permitir acessar o menu Clientes e exibir corretamente os dados dos clientes cadastrados,possibilitando a consulta das informações disponíveis. |
